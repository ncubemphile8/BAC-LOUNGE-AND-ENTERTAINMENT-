# The Hangout BAC — Lounge & Entertainment

A two-world hospitality and entertainment website for The Hangout BAC in Bulawayo.

## Experiences
- **The Lounge** — restaurant, bar and club-style nightlife, food menu, drinks enquiries, specials and WhatsApp reservations.
- **Entertainment** — weekly sessions, featured events, live countdown, ticket enquiry form and past-event archive.
- **Event gallery** — dedicated visual archive landing page for event photo stories and aftermovies.

## Features
- Distinct homepage entrances redirect to `/lounge` and `/entertainment`.
- Responsive layouts and animated editorial styling.
- Summer Garden Experience campaign for 21 December 2026.
- Live countdown to the event.
- Ticket enquiry form pre-fills WhatsApp with event, ticket category, quantity and contact details.
- WhatsApp reservations and menu enquiries.
- Past event archive and gallery framework.

## Stack
Next.js 14 · React · TypeScript · CSS · Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Import this repository into Vercel. Framework preset: Next.js. No environment variables are required for the current public-facing experience.
